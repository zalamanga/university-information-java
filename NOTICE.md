# Asal sumber

Proyek ini berasal dari latihan lokal NetBeans **Information**, package `university`. Sumber awal memuat `Person`, `student`, `Employee` (dalam `employee.java`), dan `MainMenu`.

Versi Maven mempertahankan pewarisan `Person` ke mahasiswa dan pegawai, beserta field nama, usia, universitas, program studi, ID mahasiswa, departemen, jabatan, dan gaji. Field universitas yang sebelumnya hanya dideklarasikan kini dapat diisi. Nama kelas/file disesuaikan menjadi `Student.java` dan `Employee.java`.

Nama penulis dan lisensi sumber tidak ditemukan pada berkas asal yang tersedia. Repository ini tidak menetapkan lisensi baru atau mengklaim kepemilikan eksklusif atas sumber awal.
